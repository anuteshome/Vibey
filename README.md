## Decision Status Values

Use one of the following values in the `Status` column:

* `Pending`
* `In Review`
* `Approved`
* `Rejected`
* `Deferred`
* `Superseded`

## Suggested Decision Record Format

When a decision is approved, record it using the following structure:

```md
### DEC-XXX: Decision title

- **Status:** Approved
- **Decision date:** YYYY-MM-DD
- **Owners:** Product, Architecture, Development
- **Decision:** Describe the selected decision.
- **Rationale:** Explain why this option was selected.
- **Alternatives considered:**
  - Option A
  - Option B
- **Consequences:**
  - Positive consequence
  - Trade-off or limitation
- **Affected modules:**
  - Identity
  - Onboarding
  - Documents
- **Related issues:**
  - #123
  - #124
```
